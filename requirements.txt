# JARVIS dependencies.
#
# Install with:   pip install -r requirements.txt
#
# If something fails, run `python doctor.py` — it checks every dependency
# and tells you exactly what is missing and how to fix it.
#
# NOTE: Python 3.10-3.12 only. mediapipe and torch do not yet ship wheels
# for 3.13, so installs on 3.13 will fail with confusing compiler errors.

loguru

# ----------------------------------------------------------- data and finance
pandas
yfinance
# NOTE: growwapi is deliberately NOT here. It requires protobuf>=5.29, but
# mediapipe (hand gestures, face tracking) requires protobuf<5. Both cannot be
# installed together. Gesture control is core, Groww is not, so protobuf stays
# on 4.x. If you want Groww market data and do not need gestures:
#     pip install growwapi
# ...which will upgrade protobuf and break mediapipe. yfinance covers most
# market needs without the conflict.
